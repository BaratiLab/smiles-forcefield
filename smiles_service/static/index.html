    Verify before download

    Compare GROMACS and LAMMPS energies and forces to OpenMM. Check NAMD-compatible AMBER files through independent readback.

ABOUT THE CHECKS

Validation covers one isolated geometry using vacuum settings. It establishes export consistency, not predictive accuracy or readiness for solvated production MD. Native NAMD is not run in this release.
